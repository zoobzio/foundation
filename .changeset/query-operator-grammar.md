The draft grammar is `Label: op term`: an operator is followed by a space, not a second colon, so a draft reads as its chip does. The operator is read once its space is typed and matched without case, longest first, so a multi-word operator is reached. The hint after an operator ends in a space; after a field it still ends in `: `. `labelFor` is the entry's text, so a chip's label and the draft that made it are the same string.
